# 中医经典原文数据集（corpus）

「仲景问典」使用的中医经典原文结构化数据集，开放供学习、研究与二次开发。

## 规模

| 书名 | 条数 |
|---|---|
| 伤寒论 | 515 |
| 金匮要略 | 514 |
| 素问（黄帝内经） | 570 |
| 难经（八十一难） | 81 |
| 神农本草经 | 344 |
| **合计** | **2024 条** |

另含 `formulas.json`：经方 25 条（字段 `name` / `source` / `ingredients` / `indications` / `note`）。

## 字段（books.json 每条）

| 字段 | 说明 |
|---|---|
| id | 条文序号 |
| book | 书名（伤寒论 / 金匮要略 / 素问 / 难经 / 神农本草经） |
| chapter | 篇 / 章名 |
| text | 经典原文 |
| key | 是否重点条文（bool） |
| freq | 学习热度（出现频率，int） |
| exams | 关联考试标签（执医 / 考研 / 规培） |

## 数据来源

- 伤寒论（宋版）、金匮要略方论、素问、难经：古典公版典籍结构化整理（来源 `wangekxy/classical-tcm-canon`，经 HF 镜像获取，已清洗）
- 神农本草经：孙星衍辑本（来源 `xiaopangxia/TCM-Ancient-Books`，GBK→UTF-8，仅取核心经文）

均为作者逝世逾百年的公版古籍，无版权限制；结构化整理成果以 MIT 许可开放。

## 合规

仅供中医经典学习、研究与检索。**不构成任何医疗建议、诊断或处方。**
